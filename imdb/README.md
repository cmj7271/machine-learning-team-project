기존 이진 분류 모델의 한계

본 프로젝트의 초기 목표는 IMDB 영화 리뷰 데이터에 대해
MLP 기반 Baseline 모델을 구현한 뒤, LSTM 및 LSTM + Attention 모델을 적용하여 Baseline 대비 성능 향상을 확인하는 것이었습니다.

그러나 실제 실험 결과, 복잡한 시퀀스 모델을 사용했음에도 불구하고
기존 목표였던 “Baseline 대비 명확한 성능 향상”을 달성하지 못했습니다.

1. 문제 난이도가 낮음
긍정 / 부정 이진 분류라는 비교적 단순한 문제 설정으로 인해,
텍스트의 순서 정보를 사용하지 않는 MLP Baseline 모델만으로도 충분히 높은 정확도가 나왔습니다.

2. 복잡한 모델 대비 이득이 거의 없음
BiLSTM, BiLSTM + Attention 모델을 사용했을 때 일부 설정에서는 정확도가 약간 더 높게 나오기도 했지만, 학습 과정에서 과적합이 자주 발생했고, 여러 번 반복 실험 시 MLP와 비슷하거나 오히려 더 낮은 성능을 보이는 경우도 많았습니다.

3. 첨부한 코드에서 확인 가능한 결과
첨부한 코드에서 최종 Test 정확도를 확인해보시면 MLP가 가장 안정적으로 좋은 성능을 내는 것을 확인하실 수 있습니다.

즉, 모델 구조를 복잡하게 바꾸어도 Baseline을 확실히 능가하지 못해, 성능 향상을 이루지 못했습니다.
